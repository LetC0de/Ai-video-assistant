# ── Vidora AI — Render-only requirements ──────────────────────────────────────
# Deploy target: Render (free/low-spec instance).
# Purpose: run ONLY the caption-based ingestion path in production today.
#
# Excluded on purpose (heavy; not feasible on Render's free tier yet):
#   - openai-whisper, torch, torchaudio   → local speech-to-text
#   - yt-dlp, pydub, ffmpeg-python        → no-caption YouTube / local-file audio
#   - sentence-transformers, langchain-huggingface, huggingface-hub
#                                          → replaced by Mistral cloud embeddings
#   - deep-translator                      → replaced by Mistral translation
#   - reportlab, fpdf2                     → PDF export (not part of core flow)
#   - tqdm                                 → not imported anywhere
#   - tiktoken                             → not imported anywhere
#
# When the no-caption / local-upload paths are re-enabled (after a cloud STT
# API is adopted), a build script + these libs must be added back. The backend
# imports the heavy libs lazily, so the app still BOOTS cleanly without them.
